# LoupeEdit for Claude

The Claude plugin for [LoupeEdit](https://loupeedit.com), the video editor Claude edits while you watch.

1. Install LoupeEdit from loupeedit.com and open it once.
2. In the Claude app: Customize › Plugins › Add › Add marketplace, paste `loupe-editor/claude-plugin`, click Sync, then Install LoupeEdit.

The plugin holds no editor: it starts the LoupeEdit installed on your computer (through `~/.loupe/bin`, which
LoupeEdit writes each time it starts) and carries Claude's rules for it. LoupeEdit's Help › Set up Claude… walks
through the same steps.
